# One Word, First Thought — sonder

A one-word entry for the make.fun bounty "One Word, First Thought". The program `main.ts` writes the single word "sonder" — the sudden realization that every stranger passing by has a life as vivid and complex as your own — to `/output/entry.txt`, with nothing else: no newline, no extra words.

Run it with `node main.ts` (Node 22 runs TypeScript directly).
